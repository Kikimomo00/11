# 翁蕾·AI 内容与增长作品集

当前首页为黑色背景、银白文字的四栏目圆环展示。保留人像原色，图片艺术字使用用户提供的原始素材。右上方英文目录选择栏目，滚轮、拖拽和方向键也可切换。已接入个人简介与角色专题首屏。

构图参考 [ICE WORKS](https://github.com/MegD1/Ice-works-showcase) 的屏幕外圆环和克制的文字布局；本项目使用独立的 WebGL 实现。静止时图片完整、没有粒子或循环形变。切换时，离场图片按约 1.7 像素的细颗粒遮罩碎化消散；星点使用相同的释放时序，从图片位置随机散开，范围收至图片周边，约 1 秒结束。星点脱离轮播轨道，每次切换随机方向、速度和弯曲幅度。其他图片不参与消散，标题与编号从下往上淡入，副标题稍后跟随。人像脸部椭圆保护区内液态位移严格为零，保护区外平滑过渡至更强的头发、肩颈和背景液态响应；停止移动后平复。圆线在切换及悬停图片时出现刀锋式掠光。系统开启“减少动态效果”时禁用粒子与形变；无交互且鼠标移出图片后，或页面隐藏时暂停渲染。

消散的衔接：所有图片沿圆轨道保持相同角间距，使用约 0.78 秒的统一缓动，先缓慢起步以看清碎化，再加速轮换并柔和停稳，离场图片不再单独停顿。拖拽时直接跟随手势，快速连续切换衔接前一段的向前速度。碎化按随机方向渐次推进。渲染器记录离场图片实际位置，粒子在对应像素消失的位置生成，约 70 毫秒内仍贴着图片，随后独立飘散。开头保留原图的颜色与细节，飞离后才逐渐转为柔和星点，总时长约 1 秒。

四个专项入口：

- 个人简介
- 角色创作与社区增长
- 文字作品
- AI 视觉与互动

## 预览

在项目目录启动静态服务：

```sh
python -m http.server 8765
```

然后访问 http://localhost:8765 。主要资源均随仓库提供，无需安装依赖；抽鬼牌组件保留原作者提供的远程人物头像。

## GitHub Pages

部署仓库：`Kikimomo00/11`。使用 `main` 分支根目录作为 Pages 来源；`.nojekyll` 保持静态资源原样发布。所有页面和素材采用相对路径，支持 GitHub Pages 的仓库子路径。

## 分页入场

- 角色创作：四幅画作从错落的位置依次揭开，展开后继续原有的轻微漂浮。
- 小红书穿搭账号：标题横向揭开，两张图版从相反方向展开，数据分组递进入场。
- 政务写作：标题分行出现，三类作品按文字、文稿、说明的顺序依次展开。
- AI 视觉与互动：图片从纵深聚拢状态展开成环形，文字与页码随后出现。

内嵌页面进入视野后才播放动画；离开后再次进入可重播。减少动态效果模式直接显示内容。

## 文件

- `index.html`：四栏目首页。
- `showcase.css`：黑银配色、留白和响应式排版。
- `showcase.js`：圆环切换、原色图片、局部折射和随机粒子渲染。
- `chapter.js`：角色艺术字碎片穿越画面并重组为四项成果的 Canvas 入场动画。
- `text-light.js`：内页文字随鼠标局部点亮，白色字形增加局部柔光，停止移动后保持照亮，移开后恢复。
- `evidence.js` / `evidence.css`：四项数据的浅色截图图册、不同方向幕帘转场、横向手势、独立图片滚动与原图查看。
- `archive.html`：此前的完整内容页，保留已有素材供下一步使用。
- `assets/`：首页封面及此前筛选的数据、反馈和作品素材。

## 已接入内页

- `#about/profile`：左侧彩色人像、右侧个人介绍。仅能力小标题突出，正文不做局部强调；人像在首页与内页之间连续变换位置。窄屏调整为上下排版。
- `#characters/intro`：角色创作与社区增长的第一页。一句话解释 Mufy 平台及创作内容，列出角色设定、对话设计、内容制作、社区运营；呈现用户提供的 2.5 万粉丝、4 个百万级对话量角色、千轮／万轮长对话及衍生二创。
- 角色专题入场先将用户的艺术字图片展开为银色薄片，再以四束弧形光丝和分层碎片汇聚为成果字形，伴随短暂掠光及柔和光晕，约 2.25 秒后恢复静止。无持续背景粒子。减少动态效果时直接展示内容。
- 四束光分别沿低位横掠、高位回折、浅弧与宽弧飞行，起点、束宽、尾长和到达时间错开，每次入场轻微变化，碎片与光丝共享路径。正文、数字和小标题在鼠标经过时出现半径约 86 像素的银白微紫扫光；白色文字叠加局部遮罩柔光。停手后保持光圈，没有循环动画；移开、滚动或离开页面后恢复，触屏与减少动态效果模式禁用扫光。
- 点击当前封面图片或左侧标题进入；返回控件仅显示细线箭头；支持返回目录、Esc、浏览器后退与直接内页链接。角色专题现已接入三页。

## 数据图册

点击角色专题首屏的任一数据进入对应图册，四项数据上的装饰箭头已移除。四个图册依次使用浅雾紫、冷灰蓝、鼠尾草绿和暖杏色，文字使用深墨色。整屏色板分别从下、左、上、右覆盖旧页，再从另一侧揭开新页；文字、数字和图片错开淡入与位移，无银色光幕或粒子，结束后保持静止。

桌面左侧介绍固定，右侧截图独立上下滚动；在左侧使用滚轮也仅带动右侧图片。窄屏改为固定上方简介、下方独立图片滚动。横向拖动、触屏横滑、触控板横滑、Shift + 滚轮、左右方向键和左下方 01—04 均可切换图册，保留各图册的图片阅读位置。截图支持点开完整查看，Esc 先关闭原图，再返回概览。支持浏览器前进、后退、直接链接与减少动态效果模式。

## 玻璃导航与角色页动效调整

三页导航改为底部居中的玻璃胶囊：半透明底、模糊背景、细亮边和随选中项移动的透镜。页面正文与 iframe 页脚为导航预留独立空间。角色页用固定高度网格分配卡面与画作说明，避免说明文字被 iframe 裁切。

三页间改为方向感明确的错落玻璃曲面掠过转场，旧内容与新内容分层退场/入场。曲面只在转场存在，结束后移除；快速导航使用序列标识取消过时动画及尚未载入的新页。

角色页背景恢复稀疏星尘，随机位置、半径与明暗周期，缓慢上浮。切换到其他页或进入后台时停止绘制；减少动态效果模式显示静态星尘。卡面局部亮边采用径向遮罩内的 2px 内阴影，避开小数设备像素比下 CSS border 向下取整变薄的问题。

### 最新简化

导航缩至桌面约 318 × 40px，保留单层薄玻璃外壳，删除内部活动气泡，以文字明暗区分当前页。已删除玻璃曲面转场，改为轻微位移与淡入淡出。角色星尘漂移约增加两成；第三页桌面主标题上移 8px。

三页支持键盘 ← / →，包含内嵌页面获得焦点的情况；第一页向左、最后一页向右时停在边界。忽略按住键重复、组合键及文本输入。角色详情打开时不触发章节翻页，原数据图册方向键继续由图册处理。


## 文字作品与 AI 视觉互动（当前版本）

- `writing-pages.js/css` 按叙事与内容设计、小红书穿搭账号、政务写作的顺序组织连续纵向页面。保留原来的白色幕帘入场、长文阅读与原图查看。
- `chapter-pages.js/css` 也改为连续纵向页面。滚轮直接推动内容，底部页码和左右键平滑定位；原数据图册仍可独立浏览。当前实现取代上文旧的逐页加载转场描述。
- `chapters/scroll-bridge.js` 转交嵌入文档未消费的滚动，先让内部长文和弹窗处理自身滚动；打开详情时锁住外层。
- `#ai/intro`：四张原始素材图组成滚动驱动的 3D 环形展示，原生滚动吸附。图片名称、说明和页码同步；图下注明本人使用 GPT 生成。没有点击箭头角标。
- `#ai/phone`、`#ai/story`、`#ai/cards`、`#ai/forum`：四个组件在独立 iframe 中运行，关闭后保留轮播位置并卸载组件。手机采用原有离线演示；论坛注明一次生成的回复示范，不在作品集内请求模型。
- 四个桌面代码文件与素材图复制至 `chapters/ai/`，原文件未改动。抽鬼牌去掉远程字体，原代码中的人物头像图链保留。
- 角色、文字、AI 三部分返回目录时，当前页面向上收幕，目录在下层同步恢复；个人介绍保留原人像转场。支持减少动态效果设置。
